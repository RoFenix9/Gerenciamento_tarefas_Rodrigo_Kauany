# PI-18 - Gerenciamento de tarefas domésticas

Gerenciamento de Tarefas Domésticas é um sistema web desenvolvido para ajudar famílias a organizar e acompanhar as atividades realizadas em casa de forma prática.

## OBJETIVOS 
Facilitar a organização das tarefas domésticas;
Dividir as atividades entre os moradores da casa de forma igualitária;
Identificar os responsáveis por cada tarefa;
Acompanhar as tarefas que foram realizadas e as que ainda estão pendentes;
Melhorar a organização e a colaboração entre os membros da família;

## FUNCIONALIDADES: 
As funcionalidades serão apresentadas de acordo com o desenvolvimento atual do sistema;
- Login de usuários;
- Criação de tarefas domésticas;
- Listagem das tarefas cadastradas;
- Edição de tarefas;

## TECNOLOGIAS UTILIZADAS:
- Python.
- Django.
- HTML.
- CSS.
- Bootstrap 5.3.3:.
- Bootstrap Icons:.
- SQLite:.

## PRÉ-REQUISITOS:
Para executar o projeto, é necessário ter instalado:
- Python 3.
- pip (gerenciador de pacotes do Python).
- Visual Studio Code ou outro editor de código.
- Git (opcional).

## INSTALAÇÃO E EXECUÇÃO:
1. Clone o repositório: git clone URL_DO_REPOSITORIO
2. Entre na pasta do projeto: cd projeto_tasks
3. Crie um ambiente virtual: python -m venv venv
4. Ative o ambiente virtual no Windows: venv\Scripts\activate
5. Instale o Django: pip install django
6. Execute as migrações do banco de dados: python manage.py migrate
7. Inicie o servidor: python manage.py runserver
8. Acesse o sistema pelo navegador: http://127.0.0.1:8000/
